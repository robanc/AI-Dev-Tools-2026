# Coding agent instructions

- Read `_docs/specs.md` before making any changes. It is the approved source of requirements for TaskLane.
- Keep the project small enough for a course homework assignment. Implement only the approved scope; avoid unnecessary dependencies, abstractions, and features.
- Use React with Vite and JavaScript for the frontend, with Node.js for development tooling.
- Use Python with FastAPI for the backend and uv to manage dependencies and execution.
- Use SQLAlchemy for database access and file-based SQLite for persistence.
- Include backend tests with pytest and main frontend behavior tests with Vitest and React Testing Library, following the specification. Keep test databases isolated from application data.
- Run relevant tests for implementation changes and report their results, including any checks that could not run.
- Keep local setup and testing instructions in README.md accurate as implementation is added.
- The current homework step is documentation and initial project setup only. Do not implement the frontend or backend until requested by the user.
